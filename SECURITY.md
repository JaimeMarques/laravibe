# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** form under the repository's Security tab.

Include the affected version, impact, reproduction steps, and a minimal proof of concept. Do not include real credentials, customer data, or proprietary source code.

## Scope

Laravibe is a defensive static-analysis tool. Reports deliberately omit source snippets and environment values, but users remain responsible for protecting generated reports and scanning only projects they are authorized to inspect.
